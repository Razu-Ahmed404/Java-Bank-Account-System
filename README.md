# Java Bank Account System

A simple Java-based Bank Account Management System developed to demonstrate the practical implementation of Object-Oriented Programming (OOP) concepts.

## 📌 Project Overview

The Java Bank Account System is a console-based application that simulates basic banking operations. Users can create and manage bank accounts, deposit money, withdraw money, and check account information.

This project was developed as an educational project to practice Java programming and Object-Oriented Programming concepts.

## ✨ Features

- Create bank accounts
- Store customer and account information
- Deposit money
- Withdraw money
- Check account balance
- Display account information
- Handle invalid operations
- Exception handling
- Simple console-based interface

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Exception Handling
- Console Application

## 📚 OOP Concepts Used

This project demonstrates:

- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Constructors
- `super` keyword
- Exception Handling

## 🏦 Main Operations

### Create Account

Users can create a new bank account by providing the required information.

### Deposit Money

Users can deposit money into their bank account.

### Withdraw Money

Users can withdraw money if sufficient balance is available.

### Check Balance

Users can check their current account balance.

### Account Information

Users can view their account details.
